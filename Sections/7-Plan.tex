\subsubsection{Preprocessing Pipeline}

Hoàn thành toàn bộ pipeline tiền xử lý văn bản, chạy trên PySpark:

\begin{enumerate}
    \item \textbf{Remove Gutenberg boilerplate:} Sử dụng regex để detect và loại bỏ header/footer markers (\texttt{*** START/END OF THE PROJECT GUTENBERG EBOOK ***}).
    \item \textbf{Lowercase + Regex clean:} Chuyển toàn bộ text sang chữ thường, loại bỏ ký tự đặc biệt và số.
    \item \textbf{Tokenization:} Tách văn bản thành các từ (word-level).
    \item \textbf{Stopword removal:} Loại bỏ English stopwords sử dụng danh sách NLTK.
\end{enumerate}

Output được lưu dưới dạng Parquet với schema \texttt{[book\_id, tokens, num\_tokens]}. Unit tests đã viết và pass trên sample data.

\subsubsection{Thuật toán LSH Core}

Triển khai đầy đủ 3 module chính của thuật toán LSH:

\begin{itemize}
    \item \textbf{k-Shingling (\texttt{shingling.py}):} Tạo word-level trigrams ($k{=}3$) từ cleaned tokens. Mỗi cuốn sách được biểu diễn bằng một tập hợp shingle.
    \item \textbf{MinHash (\texttt{minhash.py}):} Tính MinHash signatures với $n$ hàm hash ($n{=}100$ trên cluster). Sử dụng hash family $h(x) = (ax + b) \mod p$. Đã verify tính chất $P(h_{\min}(A) = h_{\min}(B)) \approx J(A,B)$ trên sample data.
    \item \textbf{LSH Banding (\texttt{lsh.py}):} Chia signature thành $b{=}20$ bands $\times$ $r{=}5$ rows. Hash mỗi band vào bucket. Hai tài liệu là candidates nếu chia sẻ ít nhất 1 bucket. Threshold $\approx 0.55$.
\end{itemize}

Signatures và LSH index được persist dưới dạng Parquet. Unit tests cho cả 3 module đã pass.

\subsubsection{Query Module}

Hoàn thành module truy vấn sách tương tự:

\begin{center}
\texttt{book\_id} $\rightarrow$ lookup signature $\rightarrow$ tìm candidates cùng bucket $\rightarrow$ exact Jaccard $\rightarrow$ rank $\rightarrow$ Top-K
\end{center}

Đã test thành công trên sample dataset: query một cuốn sách trả về danh sách Top-K sách tương tự kèm Jaccard score.
